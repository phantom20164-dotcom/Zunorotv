ZUNORO TV VIDEO SERVER

यह सर्वर YouTube वीडियो खोजने के लिए बनाया गया है।

VERCEL SETUP:
1. इस GitHub Repository को Vercel में Import करें।
2. Vercel में Environment Variables खोलें।
3. YOUTUBE_API_KEY नाम से अपनी YouTube API Key जोड़ें।
4. Save करें और Redeploy करें।

API ENDPOINT:
https://YOUR-VERCEL-PROJECT.vercel.app/api/youtube/search?q=test

ध्यान दें:
YouTube API Key को वेबसाइट या GitHub कोड में न डालें।
इसे केवल Vercel Environment Variables में रखें।
